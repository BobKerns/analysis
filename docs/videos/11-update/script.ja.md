シミュレーターで考える老後の資金計画。第11回は、計画を最新に保つことです。

1年前、アリスとビルは計画を作りました。そして今、1年がたちました。

## Scene `why`: なぜ最新にするのか

```slide
heading = "計画は、伝えたことしか知らない"
body = [
  "baseは、今も2026年1月の残高で始まる",

  "年に1度、または大きな変化の後に、明細からやり直す",
  "古い計画は残して、どうだったかを見る",

```

{base|ベース}は今も、アリスとビルが2026年1月に入力した残高で始まり、その後の年はすべてそこから続きます。その間に、市場は計画の想定より悪く、2人は思っていたより少し多く使いました。計画は、伝えたことしか知りません。だから年に1度、または大きな変化の後に、明細からやり直します。そして古い計画は残し、どうだったかを見られるようにします。

## Scene `roll`: 1年進める

{sim scenario roll|シム・シナリオ・ロール}は、シナリオの開始を動かします。ここでは{base|ベース}を2027年1月にします。{--keep plan-2026|キープ・プラン・ニーゼロニーロク}は、まず計画をそのまま写して残します。それから、すべての口座とロットを順に聞き、去年の実行が12月末に見込んだ額を示します。アリスとビルは、代わりに明細の額を入力します。当座預金は3万ドルではなく2万2,400ドル、普通預金は5万8千ドル、アリスのIRAは53万6千ドルではなく49万8,700ドルです。証券口座の株は29万6,500ドル。取得原価は、再投資した配当も含めて計画から出るので、Enterでそのままにします。ビルのRothは11万9,800ドルです。その取得原価は拠出額の12万ドルなので、そのままです。空欄だと、下げた年の後には減ってしまいます。バランス型ファンドには価格があるので、{roll|ロール}は口数を聞きます。1,024.8口、12月の価格で4万8,900ドルです。最後に{roll|ロール}は、自分ではできないことを伝えます。2026年の税金は、2026年の収入から、4月に払います。

## Scene `taxes`: 4月の税金のための去年の収入

計画は、毎年の税金を翌年の4月に、その年の収入から計算します。2027年1月に始まる計画には2026年がないので、何もしなければ4月の支払いはゼロになります。年を2026にした年初来の行が、それを戻します。アリスとビルのW-2の給与、1099の配当と利息、そして実現した売却益です。最後の行はお金を動かさず、{capital_gains|キャピタル・ゲインズ}から同じ口座へなので、税金にだけ数えられます。{sim ytd list|シム・ワイ・ティー・ディー・リスト}が5行を示します。

## Scene `spending`: 違っていた支出

去年の計画は、2026年の生活費を9万1千ドルと見込んでいました。明細では約9万6千ドル、月8千ドルです。そこで{base|ベース}の生活費を、2027年1月のドル、つまり基準日で、月8千ドルにします。第10回後編の{travel|トラベル}には、旅行を除いた6,500ドルの、自分の生活費のルールがあるので、{base|ベース}の変更は届きません。そちらにも自分の額、7千ドルを入れます。

## Scene `compare`: 計画と実際

{sim all|シム・オール}は、すべてを実行し直します。{base|ベース}と、その上に作った{rebalance|リバランス}と{travel|トラベル}も、一緒に2027年1月から始まります。そして{sim compare|シム・コンペア}で、{plan-2026|プラン・ニーゼロニーロク}と{base|ベース}を比べます。{start|スタート}の欄は、計画と実際です。去年の計画が12月に見込んだ額と、{base|ベース}の開始の額です。合わせて9万2千ドル少なくなっています。ほとんどは市場です。アリスのIRAで3万7千ドル、株で2万8千ドル。バランス型ファンドは計画どおりの口数ですが、価格が下がりました。当座預金の7,600ドルの不足は、多く使った分です。

## Scene `after`: これから

ここからは、今日のドルでの税引き後の純資産です。2つの計画は始まる年が違うので、{sim compare|シム・コンペア}は{base|ベース}を{plan-2026|プラン・ニーゼロニーロク}のドルにそろえ、見出しの下の行がそう示します。{base|ベース}は2027年末に8万5千ドル下回り、差は広がります。失った成長が複利で効き、月500ドル多い支出が積み重なって、2034年には12万4千ドルです。追いつくことはありません。隠すべき悪い知らせではなく、次の判断の出発点です。

残高をいくつか入力するのはすぐです。口座が多ければ、{sim import holdings|シム・インポート・ホールディングズ}がQuickenのエクスポートから残高を読み、{sim import transactions|シム・インポート・トランザクションズ}がその支出を支出のルールにします。証券会社、銀行、OFXのファイルも、これから読めるようになります。口数と価格は、価格のあるファンドでは役に立ちますが、任意です。どのロットもドルで扱えます。
