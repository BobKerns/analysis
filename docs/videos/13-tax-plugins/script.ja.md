## Scene `setup`: 年に一度

```slide
heading = "年に一度: 変わらないもの"
```

年のクラスは、州の税の1つの課税年です。その{setup|セットアップ}は、どの申告書よりも前に、年に一度だけ動きます。ファイルの先頭にあるワークシートの行を選びます。生きている二人のどちらかが70歳以上なら、その行です。それぞれの行の上限と控除の上限を、2025年からインフレで増やします。そして、固定資産税の印で使った額、家賃の印があれば家賃の5分の1を足し合わせます。どれも、試算で加える収入では変わらないので、一度だけ計算します。

## Scene `year`: 申告書ごとに

```slide
heading = "申告書ごとに: 控除"
```

それから、申告書ごとに、州の計算に加える1つの段階です。{refundable_credits|リファンダブル・クレジッツ}、払い戻される控除で、最後に引かれ、税金をマイナスにすることもあります。州の計算のもとになる連邦の申告書から調整後総所得を読み、それが収まる最初の行を探します。最後の行を超えたら、控除はありません。控除は、払った額から所得のその割合を引いたもので、上限までです。ストラテジーは1年に何千回も申告書を求めることがあるので、ここは小さくしておきます。

## Scene `rules`: 税金計算に読めるもの

税金計算に見えるのは、1つの課税年です。給与、配当、売却益といった種類ごとの収入と、誰が受け取ったか。印を付けて使った額と受け取った額。そして、もとになる申告書です。州なら連邦の申告書を読みます。速くなければなりません。ストラテジーが1か月に何度も申告書を求めることがあるからです。そして純粋でなければなりません。同じ年からは、いつも同じ申告書。年から年へ何も残しません。損失の繰り越しのように持ち越すものは、前の年の申告書から読みます。

## Scene `check`: 確かめる

{sim tax kinds|シム・タックス・カインズ}は、{property_credit|プロパティー・クレジット}を、説明の文、{state_tables|ステート・テーブルズ}のパラメーター、そして自分の4つと一緒に示します。単位と既定値も。新しいシナリオ{dc-credit|ディー・シー・クレジット}で、州税がそれを使います。パラメーターの名前を打ち間違えると、すぐに断られ、受け付けるものが示され、何も書かれません。それがなければ、既定値で合っています。印は{tax:property|タックス・プロパティー}で、二人は持ち家です。それから{sim tax check|シム・タックス・チェック}が、新しいPythonでそれぞれの申告書を2回計算し、比べます。35年で1,900行あまり、2回とも同じです。

## Scene `use`: 使う

{sim run|シム・ラン}が変更をコミットしてシナリオを実行します。{sim report tax|シム・レポート・タックス}の連邦の申告書は、今日のドルで、連邦の調整後総所得を示します。給与の最後の年、2030年は12万3千ドル。それから、社会保障とIRAがまた埋めるまで、1万5千ドル、1万1千ドルです。州の申告書が控除を示します。2031年と2032年は、上限いっぱいの約1,400ドル。払う税金がないので、税金はマイナスになり、DCが払い戻します。2033年と2034年は、上がった所得の割合で、980ドル、そして750ドル。2035年は所得が上限を超えて、控除はありません。2036年はまた下回りますが、その3パーセントで請求額がほぼ埋まり、残るのは33ドルです。

## Scene `worth`: どれだけの価値か

{sim compare|シム・コンペア}の{tax|タックス}の部分は、{dc-credit|ディー・シー・クレジット}を、控除なしで同じ世帯に課税する{dc|ディー・シー}と並べます。控除が払われるのは2035年より前の年で、約4,600ドル、ほとんどが払い戻しです。実行全体では、約3,900ドル少なく払います。払い戻しを貯めた分が、あとで少し課税される収入を生むからです。

## Scene `tradeoff`: 引き換えにするもの

```slide
heading = "控除が計画について教えること"
body = [
  "控除が払われるのは、給与と社会保障のあいだの、つなぎの年",
  "年齢が効く: 69歳なら、2034年の所得の5%で控除はなくなる",
  "崖になっている: 上限を1ドル超えると、全部を失う",
  "その年のロス転換も、それを値踏みしなければならない",
]
```

控除が払われるのは、つなぎの年です。給与が終わってから、社会保障とIRAが所得をまた埋めるまで。年齢が効きます。2034年、70歳未満なら、所得の5パーセントが請求額を上回り、控除はありません。アリスは2032年に70歳になったので、3パーセントです。そして崖になっています。上限を1ドル超えると、控除の全部を失います。つなぎの年は、ロス転換がいちばん安い年でもあります。上限を超える転換は、その税金に加えて控除も失います。控除は州の申告書にあるので、所得を加える試算には、控除がなくなるのが見えます。

## Scene `nb`: 税金のグラフ

ノートブック{net_worth|ネット・ワース}の税金のグラフは、プラグインの税金も、組み込みと同じように描きます。年ごとに連邦と州の税金を積み上げ、右の軸に実効税率を示します。つなぎの年には、州の棒がゼロより下に下がります。DCが控除を払い戻しているのです。
