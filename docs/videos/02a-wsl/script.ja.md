## Scene `title`: タイトル

シミュレーターで考える老後の資金計画。第2a回、ウィンドウズの準備です。

この回は、ウィンドウズを使う人向けです。シミュレーターは、リナックスとマックで動きます。ウィンドウズも、{WSL|ダブリューエスエル}という組み込みの仕組みで、リナックスを動かせます。数分で、アリスがそれをオンにして、第2回の出発点になるターミナルを用意します。

## Scene `why`: なぜ WSL か

```slide
heading = "なぜ WSL か"
body = [
  "WSL: Windows Subsystem for Linux",
  "ウィンドウズの中で動く、本物のリナックス (Ubuntu)",
  "マイクロソフト製で無料。Windows 10 と 11 に含まれる",
]
```

{WSL|ダブリューエスエル}は、ウィンドウズ・サブシステム・フォー・リナックスの略です。ウィンドウズの中で、{Ubuntu|ウブントゥ}という本物のリナックスを、ウィンドウズのプログラムと並べて動かします。マイクロソフト製で無料、ウィンドウズ11と、2020年以降の更新を入れたウィンドウズ10に含まれています。シミュレーターも、そのインストーラーも、道具も、すべてこのリナックスの中で、リナックスのコンピューターとまったく同じように動きます。ウィンドウズのファイルやプログラムは、そのままです。

## Scene `turn-on`: オンにする

```slide
heading = "WSL をオンにする"
note = "スタートを右クリック: ターミナル (管理者)。Windows 10 では PowerShell (管理者)"
```

オンにするのは、管理者として実行するコマンド一つです。スタートボタンを右クリックして、ターミナル、管理者を選びます。ウィンドウズ10では、ウィンドウズ・パワーシェル、管理者です。許可するか聞かれたら、はいを選びます。{wsl --install|ダブリューエスエル、スペース、ハイフン、ハイフン、インストール}と入力して、エンターを押します。リナックスに必要なものをオンにして、{Ubuntu|ウブントゥ}をダウンロードします。数分かかります。再起動するように表示されたら、コンピューターを再起動します。

## Scene `linux-user`: リナックスのユーザー名

```slide
heading = "最初の起動: リナックスのユーザー"
```

再起動すると、{Ubuntu|ウブントゥ}がひとりでに開いて、インストールを終えます。そして、リナックス用のユーザー名を尋ねます。ウィンドウズの名前と同じでなくてかまいません。小文字の一語がいちばんです。アリスは、{alice|アリス}と入力します。次に、パスワードを尋ねます。

## Scene `password`: 見えないまま打つパスワード

```slide
heading = "見えないまま打つパスワード"
note = "パスワードは、打っても何も表示されません。それで正常です。"
```

パスワードを打っても、何も表示されません。点も星も出ません。それで正常です。打ってエンターを押し、もう一度打ちます。覚えておけるものにしてください。リナックスはソフトウェアを入れる前にこれを尋ねますし、シミュレーターのインストーラーも、必要な道具を入れるために一度だけ尋ねます。すると、名前とドル記号の付いたプロンプトが出ます。これが、コマンドを待っているリナックスのターミナルです。

## Scene `open-again`: もう一度開く

```slide
heading = "Ubuntu をもう一度開く"
body = [
  "スタートメニュー: Ubuntu",
  "Windows ターミナル: タブの横の矢印から Ubuntu",
  "いつも Ubuntu を開くには: 設定、スタートアップ、既定のプロファイル",
]
```

次からは、スタートメニューで{Ubuntu|ウブントゥ}と入力して選びます。または、ウィンドウズ11に付いているウィンドウズ・ターミナルで、タブの横の小さな矢印をクリックして、{Ubuntu|ウブントゥ}を選びます。おもにシミュレーターに使うなら、ウィンドウズ・ターミナルがいつも{Ubuntu|ウブントゥ}を開くようにしましょう。設定のスタートアップで、既定のプロファイルを{Ubuntu|ウブントゥ}にします。

## Scene `files`: ファイルの置き場所

```slide
heading = "リナックスのファイルを、ウィンドウズから"
note = "またはエクスプローラーの左側の一番下にある Linux をクリック"
```

リナックスは、自分のファイルをリナックスのホームフォルダーに置きます。インストーラーがシミュレーターとデータを置くのもそこです。{retirement|リタイアメント}フォルダーの中に、コードの{analysis|アナリシス}と、家計の{data|データ}があります。ウィンドウズからも見られます。エクスプローラーで、左側の一番下にある{Linux|リナックス}をクリックします。または、アドレスバーに{\\wsl$|バックスラッシュ二つ、ダブリューエスエル、ドル}と入力します。そして{Ubuntu|ウブントゥ}、{home|ホーム}、リナックスの名前の順に開きます。

## Scene `explorer`: リナックスから

```slide
heading = "リナックスから、フォルダーをウィンドウズで開く"
note = "シミュレーターとデータは C: ではなく、リナックスに"
```

リナックスの側からは、{explorer.exe .|エクスプローラー・ドット・エグゼ、スペース、ドット}で、今いるフォルダーをエクスプローラーで開けます。逆に、ウィンドウズのCドライブは、リナックスでは{/mnt/c|スラッシュ・エム・エヌ・ティー・スラッシュ・シー}にあります。それでも、シミュレーターとデータは、インストーラーが置くリナックスのホームに置いておきましょう。そのほうがずっと速く、ギットなどのリナックスの道具も正しく動きます。

## Scene `vscode`: VS Code

```slide
heading = "リナックスで動く VS Code"
body = [
  "VS Code はウィンドウズに入れる",
  "WSL 拡張機能を追加する",
  "Ubuntu で: code ~/retirement/analysis",
]
```

ノートブックと、画像を表示できるターミナルを使うには、マイクロソフトの無料エディター、ブイエスコードを入れます。{Ubuntu|ウブントゥ}の中ではなく、いつものようにウィンドウズに入れます。拡張機能から、{WSL|ダブリューエスエル}という拡張機能を追加します。そして{Ubuntu|ウブントゥ}で、{code|コード}と入力し、続けてコードのフォルダー、{~/retirement/analysis|リタイアメント・スラッシュ・アナリシス}を指定します。ブイエスコードがそれを開き、自分の側の処理をリナックスで動かします。初回は1分ほどかかります。

## Scene `vscode-window`: VS Code のターミナルに画像を

```slide
note = "Windows ターミナルでは、グラフは画像ファイルに保存され、その場所が表示されます"
```

ウィンドウの隅に{WSL: Ubuntu|ダブリューエスエル、ウブントゥ}と出ていれば、ブイエスコードはリナックスで動いています。ノートブックもターミナルも、そこで動きます。そのターミナルにグラフを直接表示するには、設定を開いて{enable images|イネーブル・イメージズ}を検索し、ターミナル、インテグレーテッドの項目をオンにします。ウィンドウズ・ターミナルでは描けないので、同じコマンドがグラフを画像ファイルに保存し、その場所を教えてくれます。

## Scene `ready`: 第2回へ

ウィンドウズに必要なのはここまでです。ここから先は、すべて{Ubuntu|ウブントゥ}のターミナルで、マックやリナックスとまったく同じように進みます。第2回はここから始まります。{Ubuntu|ウブントゥ}を開いて、セットアップガイドにあるインストールの1行を貼り付けてください。ウィンドウズ・ターミナルでは、コントロールVで貼り付けられます。
