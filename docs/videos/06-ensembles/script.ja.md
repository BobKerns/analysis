## Scene `title`: タイトル

シミュレーターで考える老後の資金計画。第6回は、アンサンブルです。

これまでの実行は、どれも1つの答えでした。まるで市場が、毎年きっちり長期の平均どおりに増えるかのように。実際はそうはいきません。今回は、アリスとビルが計画を80通りの未来で実行し、その幅を見ます。

## Scene `monte-carlo`: 1つの計画、たくさんの未来

```slide
heading = "1つの計画、たくさんの未来"
body = [
  "メンバーの1つ1つが、計画をまるごと実行したもの",
  "それぞれが、市場とインフレを毎年引き直す",
  "メンバー0は真ん中のケース: すべての値が中央値",
  "80メンバーでざっと見る。確かめるなら400",
  "答えは1本の線でなく、幅",
]
```

モンテカルロという大げさな名前ですが、考え方は簡単です。計画を1回だけでなく、何度も実行します。1回1回をメンバーと呼び、それぞれが自分の未来を引きます。株が好調な10年もあれば、不調な10年もあります。インフレが高い未来も、低い未来もあります。メンバー0だけは例外で、すべてを真ん中の値にするので、いつも確かめられる普通のケースが1つあります。ざっと見るなら80メンバー、数字を確かめるなら400。そして答えは1本の線ではなく、全体の広がりになります。

## Scene `templates`: 用意されたテンプレート

```slide
heading = "未来は用意されている"
body = [
  "t_inflation_series、t_market_series: 長期の率(ベースが使うもの)",
  "…_ensemble: 引いた水準のまわりを、毎年新しく動く道筋",
  "…_current: 今の率をしばらく保ち、それから長期へ戻る",
  "混ぜられる出来事: 大インフレ、金融危機、パンデミックの急騰",
  "どれもシナリオなので、ほかと同じように上に作れる",
]
```

未来を自分で考え出す必要はありません。シミュレーターには、名前が{t_|ティー・アンダースコア}で始まるテンプレートのシナリオが付いています。ベースは、もうそのうち2つの上に作られています。長期のインフレと市場の率で、毎年同じです。アンサンブルのテンプレートは、それに毎年動く道筋を加えます。メンバーごとに引いた長期の水準のまわりを動きます。カレントのテンプレートは、今の率から始めて、しばらく保ち、それから長期へ戻します。混ぜて使える歴史上の出来事もあります。大インフレや、金融危機などです。どれもただのシナリオなので、ほかと同じように上に作れます。

## Scene `create`: アンサンブルを作る

{sim ensemble create|シム・アンサンブル・クリエイト}は、{sim scenario create|シム・シナリオ・クリエイト}と同じく、名前、親、ミックスインを取ります。{markets|マーケッツ}は、ベースの上に、今のインフレと市場のテンプレートを混ぜて作ります。シードは、どの未来を引くかを決めるもので、それと80というメンバー数を、どちらもテンプレートから受け継ぎます。ベースそのものは変わりません。

## Scene `varying`: 自分の行を変動させる

テンプレートは市場を変動させます。アリスとビルは、自分の行も変動させられます。2031年の新しい車は4万ドルでしたが、本当のところはわかりません。{sim calendar edit|シム・カレンダー・エディット}で、その行に名前と幅を付けます。三角分布で、少なくとも3万、いちばんありそうなのが4万、ひょっとすると5万5千。この行はベースのものなので、編集は{markets|マーケッツ}に上書きの行を書き、ベースは4万ドルのままです。

## Scene `factors`: いっしょに動くもの

```slide
heading = "ファクター: いっしょに動くもの"
body = [
  "ファクターは共通の影響で、それ自体は値ではない",
  "コアインフレ → 金利 → 現金の利回り",
  "コアインフレ → 消費者物価指数 → 物価",
  "だから高いインフレには、高い金利が伴いやすい",
  "テンプレートの木は、100年の歴史から",
]
```

どの値もばらばらに引いたら、おかしな未来になります。インフレは高いのに金利はどん底、それが何年も続く、というように。現実には、これらはいっしょに動きがちです。テンプレートは、ファクターでそれを結び付けます。ファクターは共通の影響で、それ自体は値ではありません。いちばん上にコアインフレがあり、その下に消費者物価指数が、そして金利が、さらにその下に現金の利回りがあります。どれくらい強く従うかは、100年の歴史から測ったものです。

## Scene `pair`: 引いた値で確かめる

{sim ensemble draws|シム・アンサンブル・ドローズ}は、各メンバーが何を引いたかを示します。{--pair|ダッシュダッシュ・ペア}を付けると、2つの値を互いに対して描きます。ここでは、横に各未来の長期のインフレ、縦に現金の利回り。いっしょに上がっています。木から見込まれる相関はおよそ0.8で、引いた値もそれに近くなりました。インフレが高い未来では、たいてい現金の利回りも高いのです。

## Scene `run`: 実行する

{sim run|シム・ラン}は、{markets|マーケッツ}がアンサンブルだと見て、すべてのメンバーを、コンピューターのプロセッサーの数だけ同時に実行します。計画をまるごと80回実行して、ここではおよそ30秒です。各メンバーは自分の実行ファイルを持ち、1回分がまとめて1つのフォルダーに入ります。

## Scene `fan`: ファンチャート

{sim ensemble summary|シム・アンサンブル・サマリー}に{--chart|ダッシュダッシュ・チャート}を付けると、ファンチャートを描きます。税引き後の純資産を、今のドルで表したものです。いちばん濃い帯が、真ん中の5分の1の未来。薄い帯は、いちばん運の良い5%と悪い5%の手前まで広がります。2060年、真ん中の未来は約160万ドルで終わり、ベースの1回の実行より少し下です。でもファンの上の端は1000万ドルを超え、下の端はゼロ近くまで下がります。

## Scene `table`: その数字

{--chart|ダッシュダッシュ・チャート}なしでは、同じ数字が表で出ます。1行が1年です。平均、中央値、そして帯の境目になるパーセンタイル。注目すべきは最後の2列です。{cvar05|シーバー・ゼロ・ゴー}は、いちばん悪い5%の未来の平均で、2060年には2万ドルを切ります。そうした未来では、アリスとビルはほとんどお金を使い果たします。

## Scene `reading`: 読み方

```slide
heading = "読み方"
body = [
  "中央値は真ん中の未来。平均は、ごく少数の幸運な未来に引き上げられる",
  "帯: たいていの未来が落ち着くところ",
  "cvar05、cvar20: いちばん悪い5%と20%の平均",
  "悪い未来がましなほど、安全な計画",
  "差が小さいときは、信じる前にメンバーを増やす",
]
```

いくつか覚えておきたいことがあります。中央値は真ん中の未来です。平均はそれより上にあり、ごく少数のとても幸運な未来が引き上げています。帯は、たいていの未来が落ち着くところを示します。末尾の平均、{cvar5|シーバー・ゴー}と{cvar20|シーバー・ニジュウ}は、悪い未来がどれほど悪いかを示します。安全のために大事なのはそこです。平均がどれだけ良いかではなく、どこまで悪くなるか。そして80メンバーでは、小さな差は雑音です。信じる前に、メンバーを増やして実行しましょう。

## Scene `compare`: 同じ未来で、もしもの案を

では、第5回の疑問をもう一度。ビルがあと2年働いたら? {work-longer-mc|ワーク・ロンガー・エムシー}は、{markets|マーケッツ}の上に作り、{work-longer|ワーク・ロンガー}の案を混ぜます。{markets|マーケッツ}のシードを受け継ぐので、そのメンバー1は{markets|マーケッツ}のメンバー1と同じ未来を引き、ほかも同じです。だから{sim ensemble compare|シム・アンサンブル・コンペア}は、未来ごとに比べられます。2031年からは、80通りの未来のすべてで長く働くほうが上回り、いちばん悪い5%の平均も10万ドル以上よくなります。つまり答えはイエス。助けがいちばん必要なところで、いちばん役に立ちます。

## Scene `compare-chart`: 比較を描く

{--chart|ダッシュダッシュ・チャート}を付けると、比較を描きます。上は、未来ごとの差をファンにしたもの。2031年までは、第5回で説明した税の理由で少し下回り、それからは大きく上回ります。下は、いちばん悪い5%と20%の変化、そして各パーセンタイルの変化です。

## Scene `nb-ensemble`: アンサンブルのノートブック

アンサンブルのノートブックは、同じものを操作しながら見せます。レシピと、必要なら口座を選ぶと、年末の表の上にファンチャートを描きます。年のスライダーで、ここでは最初の15年に寄ります。その下には、基準と比べる相手を選ぶ一対一の比較があり、さらにその下に、ガードレール、支出、そしていくつものレシピを並べる表があります。

## Scene `ai`: AIに聞く

```slide
heading = "AIにアンサンブルを聞く"
body = [
  "「markets で、いちばん悪い未来に共通するのは?」",
  "「純資産が25万ドルを切る見込みは?」",
  "「どの変動する行がいちばん効いている?」(sim ensemble sensitivity)",
]
```

AIアシスタントは、アンサンブルも読めます。いちばん悪い未来に共通するものや、純資産がある額を切る見込みを聞いてみましょう。そして、どの変動する行がいちばん効いているかは、{sim ensemble sensitivity|シム・アンサンブル・センシティビティ}がそれぞれの効き目を測ります。やり方は、アンサンブルのガイドにあります。
