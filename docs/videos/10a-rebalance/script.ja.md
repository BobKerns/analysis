## Scene `title`: タイトル

シミュレーターで考える老後の資金計画。第10回の前編は、リバランスです。

前回は、ガードレールを越えたら支出を減らすストラテジーでした。今回は、アリスとビルの投資を、2人が選んだ配分に保つストラテジーです。

## Scene `strategy`: ルールとストラテジー

```slide
heading = "ストラテジーは、進みながら判断する"
body = [
  "ルールは何が起きるかを決める: 毎月7,500ドルを生活費に",
  "チェーンはお金の出どころを、決まった順番で決める",
  "ストラテジーは毎回、その月の残高から判断する",
  "チェーン、または印の付いたルールを受け持つ",
  "ストラテジーがなければ、チェーンの順番が決める",
]
```

予定のルールは、何が起きるかを決めます。毎月7,500ドルを生活費に。チェーンは、そのお金がどこから来るかを、いつも同じ順番で決めます。ストラテジーは、その月の残高を見て、毎回判断します。第9回のように、チェーンか、印の付いたルールを受け持ちます。止めれば、またチェーン自身の順番が決めます。

## Scene `mix`: 配分はどうずれるか

{sim allocation --opening|シム・アロケーション・ダッシュダッシュ・オープニング}は、始めの資産を資産クラスごとに示します。株が約78パーセント、債券が15パーセント、それに少しの現金です。株は{stock|ストック}と{stock_us|ストック・ユーエス}の2つのクラスに分かれていますが、これはすぐ後で扱います。支出チェーンは、まず貯蓄口座、次に証券口座の債券、その株、そしてアリスのIRAから引き出します。税金を考えて選んだ順番です。{sim account history|シム・アカウント・ヒストリー}は、それが債券に何をするかを示します。2030年までは変わりませんが、その後、つなぎの年と車の代金を払い、2033年には無くなります。それからは、誰も決めていないのに、アリスとビルは株しか持っていません。

## Scene `classes`: すべてのロットにクラスを

```slide
heading = "ポートフォリオのロットには、すべて資産クラスが要る"
body = [
  "銘柄の比率から(第8回)",
  "または、ロットそのものの行から: 口座:ロット",
  "または、成長の系列から: stock_us、bond など",
  "分類のないロットが1つあると、すべての割合が狂う",
]
```

資産クラスで舵を取るストラテジーは、すべてのロットのクラスを知っていなければなりません。投資信託を持つロットは、第8回のように、その比率からクラスが決まります。銘柄のないロットには、口座とロットの名前で、そのロットだけの行を作れます。それもなければ、成長の系列からクラスが決まります。IRAとロスは{stock|ストック}という系列で、証券口座の株は{stock_us|ストック・ユーエス}で成長します。アリスとビルは3つともアメリカの株だと考えているので、そう書きます。

## Scene `targets`: ポートフォリオとその目標

新しいシナリオ{rebalance|リバランス}を作ります。ポートフォリオとは、同じ印の付いた口座のことです。{portfolio:invest|ポートフォリオ・インベスト}を、証券口座、アリスのIRA、ビルのロスに付けます。{sim symbol add|シム・シンボル・アッド}に、銘柄の代わりに口座とロットを渡すと、IRAをアメリカの株に分類できます。ロスも同じです。{sim target set main|シム・ターゲット・セット・メイン}は、アメリカの株80パーセント、債券20パーセント。{sim allocation|シム・アロケーション}は、投資が2種類になったことと、すでに株が5ポイント多いことを示します。

## Scene `add`: リバランスのストラテジー

{sim strategy kinds rebalance|シム・ストラテジー・カインズ・リバランス}は、組み込みの種類を説明します。どのクラスも、決めた幅、初めは5ポイントの内側にある間は、チェーン自身の順番が決めるので、税金を考えた順番はたいてい守られます。幅を越えると、引き出しを少しずつに分け、それぞれを、配分を目標に最も近づけるロットから取ります。{sim strategy add draw|シム・ストラテジー・アッド・ドロー}、種類は{rebalance|リバランス}、支出チェーンに、ポートフォリオの印と目標を付けます。省けば、コマンドが1つずつ聞いてきます。

## Scene `invest`: 少なすぎるところへ投資する

お金は入ってもきます。第7回では、当座預金の3万ドルを超えた分が、証券口座の株に移されます。投資先のチェーン{invest|インベスト}を作り、株、次に債券を並べ、当座預金のあふれ先をそこに向け、同じポートフォリオと目標で、専用のストラテジー{place|プレイス}を付けます。これで、あふれたお金は少なすぎるほうへ行きます。{sim strategy list|シム・ストラテジー・リスト}が2つを並べます。

## Scene `log`: 何をしたか

実行します。{--commit|ダッシュダッシュ・コミット}は、先に変更を保存します。{sim strategy log|シム・ストラテジー・ログ}は、判断を1つずつ並べます。2026年8月、債券は目標の20パーセントに対して15パーセントなので、あふれたお金のうち約6,700ドルを債券に入れます。2029年には株が85パーセントを超えるので、当座預金の補充は株から取ります。{sim explain|シム・エクスプレイン}が合計を出します。引き出しが437回で120万ドル、投資が10回で約50万ドル。{sim allocation --drift|シム・アロケーション・ダッシュダッシュ・ドリフト}は、毎年末の配分のずれをグラフにします。実行全体を通して約5ポイント、幅の端にとどまります。

## Scene `nb-drift`: 口座のノートブック

口座のノートブックは、同じずれを月ごとに描きます。幅には色が付き、ストラテジーが動いた月ごとに、軸に印が付きます。

## Scene `off`: ストラテジーなし、ストラテジーあり

その価値はあったでしょうか? {rebalance|リバランス}の上に作ったシナリオで、2つのストラテジーを止めます。{sim strategy edit --disable|シム・ストラテジー・エディット・ダッシュダッシュ・ディセーブル}です。ほかはすべて同じです。{sim compare|シム・コンペア}のストラテジーの節が、2つを並べます。ストラテジーがないと、配分は2026年に幅を越え、2033年からは20ポイントずれて、株だけになります。あると、5ポイントの近くにとどまります。そして純資産は、ストラテジーの違いだけを見るために税引き前で比べると、リバランスのほうが2060年に約45万ドル少なくなります。間違いではありません。順調な1つの未来では、債券20パーセントは、株だけよりも増え方が小さいのです。

## Scene `why`: リバランスは何のためか

```slide
heading = "リバランスは、悪い未来のため"
body = [
  "1つの未来: 債券が少ないほど増える",
  "多くの未来: 債券が悪い未来を和らげる",
  "真ん中は下がり、最悪は良くなる",
  "アンサンブル全体で判断する",
]
```

順調な1つの未来では、リバランスが何のためにあるのかは見えません。株が多いほど、良い未来はもっと良く、悪い未来はもっと悪くなります。配分を決めておくことは、真ん中を少し手放して、底を守ることです。それを見るには、多くの未来、つまりアンサンブルが要ります。

## Scene `mc`: それぞれ80の未来

第6回と同じように、インフレと市場が変わる80の未来のアンサンブルを2つ作ります。{rebalance-mc|リバランス・エムシー}と{no-rebalance-mc|ノー・リバランス・エムシー}です。同じテンプレートと同じシードから作るので、一方の5番目の未来は、もう一方の5番目と同じ市場を見ます。実行には、それぞれ1、2分かかります。

## Scene `mc-compare`: 得られたもの

{sim ensemble drift|シム・アンサンブル・ドリフト}は、ばらつきを示します。ストラテジーがないと、2033年にはどの未来も20ポイントずれています。あると、ふつうの未来は幅の近くにとどまります。いちばん悪い年には、20に1つの未来が約13ポイントまでずれます。ストラテジーは、どのみち動くお金でしか舵を取れないからです。{sim ensemble compare|シム・アンサンブル・コンペア}は、未来を対にして比べます。真ん中では、リバランスのほうが少なく、その差は年とともに広がり、上回るのは5つに1つの未来だけです。でも大事なのは下のグラフです。最悪の5パーセントの未来は、2044年から2056年まで、たいていの年末に約3万ドル多く残り、最悪の20パーセントは約1万5千ドル多く残ります。上は少し低く、底は高く。その取り引きに価値があるかどうかは、アリスとビルが決めることです。

## Scene `nb-compare`: 比較のノートブック

シナリオ比較のノートブックは、それぞれの実行のずれを、幅に色を付けて並べて描き、その下に、それぞれのシナリオのストラテジーが動かした金額を示します。アンサンブルのノートブックにも、すべての未来の同じずれがあります。

## Scene `ai`: AIに聞く

```slide
heading = "AIにリバランスを聞く"
body = [
  "「5ポイントの幅は、私たちに合っている?」",
  "「年を取るにつれて、目標を変えるべき?」",
  "「債券は、どの口座で持つべき?」",
]
```

ここでもAIアシスタントが役に立ちます。幅をどれだけにするかを一緒に考え、いくつかをアンサンブルで試せます。年齢とともに目標を変えるグライドパスを説明してくれます。変えるたびに、{--as-of|ダッシュダッシュ・アズ・オブ}を付けた新しい目標になります。そして、債券をどの口座で持つかも相談できます。それは配分だけでなく、税金も変えます。
