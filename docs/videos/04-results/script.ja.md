## Scene `title`: タイトル

シミュレーターで考える老後の資金計画。第4回は、結果を見ます。

アリスとビルのベースシナリオは実行できるようになりました。では、その結果は何を語っているのでしょう。今回は、実行結果の見方を紹介します。ターミナルでのざっとした要約、税引き後の純資産、収入と支出と税のレポート、そしてノートブックのグラフです。

## Scene `networth-graph`: 純資産をひと目で

{sim networth --chart|シム・ネットワース・チャート}は、ベースの計画を、今から2060年まで描きます。実線は、今日のドルでの税引き後の純資産、その横の破線は税引き前の合計で、そのあいだの差が、まだ払っていない税です。ふたりが働く間は増え、給料が止まって車を買うと下がり、また増えていきます。画像を出せないターミナルでは、グラフをファイルに保存します。どのレポートも、同じように{--chart|チャート}を付けられます。{--table|テーブル}も付けると、グラフの下に数字も出ます。

## Scene `after-tax`: ここでの純資産の意味

```slide
heading = "使えるお金としての純資産"
body = [
  "税引き後: まだ払っていない税を引いた額",
  "IRAの引き出しと含み益には、使うときに税がかかる",
  "今日のドルで: インフレを除いて",
  "--pre-tax と --dollars nominal で元の合計",
]
```

なぜ税引き後なのでしょう。アリスの従来型{IRA|アイ・アール・エー}にある1ドルは、そのまま使える1ドルではありません。引き出すときに税がかかります。証券口座の株の含み益も同じです。そこでシミュレーターは、まだ払っていない税を引いた純資産を見せます。その税は、お金を10年かけて引き出したとして、その年の税率表で計算します。さらに、インフレを除いた今日のドルで見せるので、2060年と2026年を公平に比べられます。2つのオプションで、元の合計を見ることもできます。

## Scene `networth`: 年ごとの純資産

{--chart|チャート}を付けなければ、{sim networth|シム・ネットワース}は、グラフのもとになる数字を、毎年の年末について見せます。純資産は、持っているものすべてから借りているものを引いた額です。繰り延べ税は、IRAと含み益がまだ払っていない税、未払い税は、終わった年の税で、翌年の4月に払うものです。残りが税引き後です。2060年には、今日のお金でおよそ180万ドルです。{--pre-tax|プリ・タックス}と名目ドルを指定すると、同じ実行が、将来のドルでの元の合計を見せます。580万ドルを超えます。同じ計画ですが、計画に使うべきなのは最初の数字です。

## Scene `runs`: 実行はファイルになる

実行は、シナリオを1か月ずつ先へ進め、すべてを1つのファイルに保存します。すべての残高、動いたすべてのドル、毎年の税です。{sim list|シム・リスト}で、これまでの実行が見られます。この3つは第3回の実行です。補充チェーンを作る前、作った後、そしてカレンダーの出来事を入れた後です。ファイルの名前は、実行した時刻とシナリオです。実行結果を見るコマンドは、別のものを指定しない限り、シナリオの最新の実行を読むので、この名前を使うことはあまりありません。古い実行は、新しいものをいくつか残して、しばらくすると片付けられます。

## Scene `explain`: ざっと見る、そして古い実行

古い実行を見るには、そのファイルを指定します。これは最初の実行、補充チェーンを作る前のものです。{sim explain|シム・エクスプレイン}は、まず実行の出どころを示します。実行したコードとデータ、そして何か月分か。次に、最後の時点の各ロット、毎年の純資産、そしていちばん下に不足があります。2032年11月に当座預金がマイナスになり、それを補う補充チェーンはありませんでした。チェーンがあれば、この行にそれが何をしたかが出ます。ガードレールのあるシナリオでは、それを越えた年の続きも出ます。それは第9回で扱います。名前を指定しない最新の実行には、マイナス残高はひとつもありません。

## Scene `history`: 1つの口座の推移

{sim account history|シム・アカウント・ヒストリー}は、1つの口座を追います。当座預金は、ふたりの給料が入る間は増え、給料が止まって車を買うと減ります。2032年と2033年には最低残高の5千ドル近くにとどまり、補充チェーンが足しています。そして、ビルの社会保障の年金とアリスの必要最低分配が始まると、また増えていきます。ロットを指定すると、取得原価と含み益も見られます。証券口座の株は毎年増え、チェーンが一部を売るたびに、取得原価も一緒に減っていきます。

## Scene `income`: お金はどこから来たか

{sim report income|シム・レポート・インカム}は、ある年の収入を種類ごとに、それぞれの割合とともに見せます。ビルが働く最後の年、2030年は、まだ給料がいちばん大きな部分です。2031年には給料がありません。社会保障の年金と投資が支えます。投資には、売ったかどうかにかかわらず、持っているものの値上がりも入ります。{--year|イヤー}を付けなければ、すべての年の表になり、それぞれの年を、収入から、税と支出を経て、純資産の変化まで追います。幅が広いので、グラフが向いています。{--chart|チャート}で描けますし、ノートブックで探ることもできます。

## Scene `expenses`: 支出と利益

{sim report expenses|シム・レポート・エクスペンシズ}は、支出を種類ごとに見せます。生活費、医療費、税を、毎年です。2031年には車があり、2036年からは生活費が下がります。{sim report gains|シム・レポート・ゲインズ}は、投資の側を分けて見せます。実現して税がかかった利益、税のかからなかった利益、そしてまだ紙の上の値上がりです。最後の列は、入ってきた現金で支出がまかなえたかどうかを示し、まかなえなかったときは、補充チェーンが投資を売って残りを出しました。

## Scene `tax`: 年ごとの税

{sim report tax|シム・レポート・タックス}は、毎年の連邦所得税を、申告書と同じ順に見せます。調整後総所得、控除、残った課税所得、税、そして全体に対する実効税率です。給料が入っている間は、およそ13パーセントです。その後、課税するものがほとんどない年が数年続き、ビルの社会保障の年金が始まり、2035年にはアリスの必要最低分配が始まります。州の所得税のルールがあれば、その列も加わります。税については第7回で詳しく扱います。

## Scene `nb-networth`: グラフで見る純資産

純資産のノートブックです。いちばん上でシナリオ、ベースを選びます。グラフは税引き後の純資産で、名目ドルと今日のドルの両方です。{Pre-tax|プリ・タックス}を押すと元の合計になり、{After-tax|アフター・タックス}で税をまた引きます。年のスライダーは、実行の一部を拡大します。ここでは引退前後の年です。ノートブックのすべてのグラフが、いっしょに絞り込まれます。

## Scene `nb-income-tax`: グラフで見る収入と税

さらに下には、レポートがグラフで並んでいます。経済的所得は、{sim report income|シム・レポート・インカム}の幅の広い表です。ゼロより上が、その年に税引き後で入ってきたもの、下が、支出とインフレが持っていったもの、そして黒い線が純資産の変化です。2031年の車がはっきり見えます。税のグラフは、毎年の税を、実効税率を別の目盛りにして示します。どのグラフの下にも、その表があります。

## Scene `nb-accounts`: グラフで見る1つの口座

口座のノートブックは、1つの口座の残高を、実行の全期間にわたって描きます。当座預金を選ぶと、増えて、最低残高まで減り、また増えるのが見えます。証券口座を選ぶとロットが現れ、株を選ぶと、そのロットだけが見られます。

## Scene `nb-events`: 動いたすべてのドル

出来事のノートブックは、実行が動かしたすべてのドルを、その理由とともに一覧にします。どのルールか、あるいは補充かです。{refill|リフィル}を選ぶと、当座預金が補充されたすべての時が、チェーンのどの口座からかとともに、それを必要とした支払いに結びつけて見られます。2033年3月に普通預金が尽きると、債券が引き継ぎます。売るたびに、その一部は払った元本の払い戻し、一部は利益です。数字に驚いたら、ここで理由を探せます。

## Scene `nb-overview`: 設定をひと目で

そしてシナリオの概要は、実行しなくても、設定そのものを見せます。人、口座、チェーン、ルール、カレンダーの出来事で、補充チェーンは流れ図で描かれます。実行結果を信じる前に、シナリオが思ったとおりになっているかを確かめるのに役立ちます。
