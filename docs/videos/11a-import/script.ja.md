## Scene `title`: タイトル

シミュレーターで考える老後の資金計画。第11a回は、データの取り込みです。

アリスとビルは、口座をもう{Quicken|クイッケン}で管理しています。同じ数字を、計画にもう一度打ち込む必要があるでしょうか。

## Scene `contents`: すでにあるファイルから

```slide
heading = "すでにあるファイルから"
body = [
  "残高: それぞれの口座にあるもの",
  "支出: 1年分を、支出のルールに",
  "外の名前は一度だけ対応させ、覚えておく",
  "今はQuickenから。ほかの取り込み元も同じやり方",

```

この回は第11回からの寄り道で、口座がいくつもある人向けです。取り込むものは二つあります。残高、つまりそれぞれの口座にあるもの。そして支出で、1年分を支出のルールにします。今は{Quicken|クイッケン}のレポートを読みます。ほかの取り込み元もこれから加わり、同じやり方で使えます。

## Scene `idea`: 名前を一度だけ対応させる

```slide
heading = "名前を一度だけ対応させる"
body = [
  "Quickenでは: Joint Checking、Groceries",
  "計画では: Asset_Checking、Expense_Living",
  "最初の取り込みが、どれがどれかを尋ねる",
  "答えは保存され、すべてのシナリオで使われる",
]
```

外のファイルで困るのは、名前です。{Quicken|クイッケン}は、ある口座を{Joint Checking|ジョイント・チェッキング}と呼びます。計画では{Asset_Checking|アセット・チェッキング}です。そこで最初の取り込みは、外の名前の一つ一つについて、計画のどの口座のことかを尋ねます。答えは保存され、すべてのシナリオで使われます。その後の取り込みは、コマンド一つです。

## Scene `export`: 二つのレポートをエクスポートする

```slide
heading = "二つのレポートを、CSVでエクスポート"
note = "Quickenで: 計画の最初の日の純資産レポートと、去年の取引"
```

アリスは{Quicken|クイッケン}から、レポートを二つ、{CSV|シーエスブイ}ファイルでエクスポートします。一つは純資産のレポートで、計画が始まる日のものです。すべての口座と、その残高が載っています。もう一つは、去年の取引です。どちらも、ダウンロードのフォルダーに入ります。

## Scene `sources`: ファイルの形式を確かめる

{sim import sources|シム・インポート・ソーシズ}は、シミュレーターが読める形式を並べます。今は{Quicken|クイッケン}の、残高用と取引用です。ファイルを渡すと、それぞれがどの形式かを答えます。これでアリスは、何も取り込まないうちに、二つとも読めると分かります。

## Scene `holdings`: 残高と、一度だけの質問

{sim import holdings|シム・インポート・ホールディングズ}は、純資産のレポートを読みます。どの名前も初めて見るので、一つずつ尋ね、選べるように計画の口座を並べます。{Joint Checking|ジョイント・チェッキング}は{Asset_Checking|アセット・チェッキング}。{Online Savings|オンライン・セービングズ}は{Asset_Savings|アセット・セービングズ}です。証券口座は違います。{Quicken|クイッケン}のレポートには数字が一つしかなく、計画では株と債券の二つのロットです。一つの数字で二つのロットは埋められないので、アリスは{skip|スキップ}と答え、この二つは自分で入力し続けます。二つの退職口座は、計画のものと合います。家とクレジットカードは計画にないので、これも{skip|スキップ}です。{skip|スキップ}もほかと同じ答えで、保存され、二度と尋ねられません。それから、残高の前と後を示します。当座預金は1万5千ドルと入力してありましたが、レポートでは1万4,820ドルです。二つの退職口座には、去年の年末の残高も入れます。必要最低引き出し額は、そこから計算されます。四つのロットが更新され、答えが保存されました。

## Scene `again`: もう一度実行する

答えは、ふつうのファイルです。外の口座ごとに1行で、{map|マップ}と計画の口座、または{skip|スキップ}です。答えを変えるには、その行を編集します。今度は{--dry-run|ドライ・ラン}を付けて、もう一度取り込みます。何が変わるかを示すだけで、何も書きません。どの名前にも答えがあるので、質問はありません。そして、変わるものもありません。計画はもう、レポートのとおりだからです。来年、新しいレポートでは、これがすべてです。コマンド一つです。

## Scene `categories`: カテゴリーをまとめる

支出には、アリスが自分で書くファイルが一つあります。{Quicken|クイッケン}にはカテゴリーが何十もありますが、計画に要るのは少しだけです。このファイルが、それをまとめます。{Groceries|グローサリーズ}と{Restaurants|レストランツ}は{Food|フード}に。{Utilities|ユーティリティーズ}と{Home Repair|ホーム・リペア}は{Home|ホーム}に。{Shopping|ショッピング}は{Everyday|エブリデー}になります。書かなかったカテゴリーは、{Other|アザー}に入ります。

## Scene `estimates`: 見積もりをどける

第3回で、アリスとビルは見積もりを二つ入力しました。生活費が月7,500ドル、医療費が月900ドルです。取り込みはこれから、実際に使った額からルールを書きます。両方あると二重に数えられるので、先に二つの見積もりを消します。

## Scene `transactions`: 支出が支出のルールになる

{sim import transactions|シム・インポート・トランザクションズ}は、1年分を読み、カテゴリーごとに平均の月の額を出します。{--from-account|フロム・アカウント}は、お金の出どころで、当座預金です。それから、カテゴリーごとに、どの支出の口座に入れるかを尋ねます。{Health|ヘルス}は医療費に、残りは生活費にします。カテゴリーごとに、毎月の、インフレとともに上がるルールが一つ書かれます。{Everyday|エブリデー}は月4,300ドル、{Food|フード}は1,050ドルです。合わせて月およそ7,700ドルで、アリスとビルの見積もりは8,400ドルでした。どのルールにも、生成されたという印が付きます。だから来年の取り込みは、この六つを置き換え、手で書いたルールには触れません。

## Scene `saved`: 保存されるもの

```slide
heading = "importsフォルダー"
body = [
  "accounts.csv: 外の口座ごとに、対応かスキップ",
  "categories.csv: 外のカテゴリーを、自分のものにまとめる",
  "expense_accounts.csv: カテゴリーごとの支出の口座",
  "すべてのシナリオで共有。名前の変更にもついていく",
]
```

取り込みが覚えたことは、すべて一つのフォルダーにあります。シナリオのフォルダーの隣の、{imports|インポーツ}です。すべてのシナリオが共有するので、もしものシナリオで、また尋ねられることはありません。計画の口座の名前を変えると、保存された答えもついていきます。そして、答えにある口座がそのシナリオにないときは、そのシナリオのためだけに尋ね、ほかのシナリオのための答えは残します。

## Scene `others`: ほかの取り込み元

```slide
heading = "ほかの取り込み元"
body = [
  "今: Quickenのレポート",
  "これから: 証券会社、銀行、OFXのファイル",
  "証券会社のファイルは保有ごとなので、すべてのロットを埋められる",
  "ガイドに、取り込み元ごとのエクスポートのしかた",
]
```

{Quicken|クイッケン}は、最初の取り込み元です。証券会社や銀行のファイル、{OFX|オーエフエックス}のファイルも、これから読めるようになります。証券会社のファイルには保有が一つずつ載っているので、{Quicken|クイッケン}の一つの数字では埋められなかったロットも埋められます。どの取り込み元でも、手順は同じです。エクスポートして、一度答えて、取り込みます。ガイドには、取り込み元ごとに、何をエクスポートするかが書いてあります。
