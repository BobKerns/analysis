## Scene `title`: タイトル

シミュレーターで考える老後の資金計画。第1回は、このシミュレーターに何ができて、どう動くのかを紹介します。

アリスとビルを紹介しましょう。アリスは2028年に退職する予定で、ビルはその2年後です。この年代の多くの人と同じように、ふたりの貯蓄はいくつかの種類の口座に分かれていて、聞きたいことがたくさんあります。

## Scene `questions`: 答えを出せる問い

```slide
heading = "答えを出せる問い"
body = [
  "いつ退職できて、いくら使えるか？",
  "どんな資産配分が合っているか？",
  "家を売るのは今か、5年後か？",
  "ロス転換で何が得られるか？",
  "計画にはどれだけ余裕があるか？",
]
```

いつ退職できて、退職後はいくら使えるのでしょうか。どんな資産配分がいちばん合っているのでしょうか。家を売るのは今がいいのか、5年後がいいのか。そして小さな家に住み替えるべきか。{IRA|アイ・アール・エー}の一部をロス口座に転換すると、実際に何が得られるのか。市場が期待を下回ったとき、計画にはどれだけ余裕があるのか。

このシミュレーターは、こうした問いに、あなたの家計に合わせて答えるためのものです。それぞれの選択を先まで進めてみて、並べて比べます。

## Scene `model`: 家計のモデル

```slide
heading = "家計のモデル"
body = "すべての口座を月ごとに。入ってくる収入、出ていく支出、自分で書くルールで動くお金、そして毎年の税金。"
```

成長率をひとつ入れるだけの計算機ではありません。口座を月ごとにモデル化します。給料や年金が入り、支出が出ていき、自分で書いたルールに従って口座の間をお金が動きます。毎年の税金も計算します。最低引き出し額の義務や、メディケアの所得に応じた上乗せ保険料も含めてです。だから答えは、実際に使える金額になります。

## Scene `data`: データは自分のもの

```slide
heading = "データは自分のもの"
body = "自分のフォルダーにあるプレーンテキストのファイルを、バージョン管理で。どこにもアップロードしません。"
```

数字はすべて、自分のフォルダーにあるプレーンテキストのファイルに入っていて、バージョン管理されています。プログラムとは別の場所です。どこにもアップロードされません。そして実行のたびに、どのバージョンのデータとプログラムで計算したかが、きちんと記録されます。

## Scene `scenarios`: シナリオは積み重なる

計画のことをシナリオと呼びます。たいていのシナリオは、別のシナリオの上に積み重ねて作ります。ここでは、{base|ベース}が全体の前提、つまり長期のインフレ率と市場の利回りを持っています。アリスの計画、{retire alice|リタイア・アリス}は、{base|ベース}の上に家計の中身、つまり口座、収入、支出を加えます。{bill early|ビル・アーリー}は「もしも」のシナリオで、ビルが1年早く退職する場合です。{retire alice|リタイア・アリス}の上に作られていて、中身は変更ひとつだけ、ビルの給料が1年早く終わることです。{base|ベース}で何かを直せば、その下のシナリオはすべて、その修正を受け継ぎます。いちばん上の{alice crisis|アリス・クライシス}には、最後にまた戻ってきます。

## Scene `run`: 実行する

計画がどこへ向かうかを見るには、実行します。シミュレーターは開始日から終了日まで一か月ずつ進み、起きたことをすべて実行ファイルに書き出します。すべての残高、すべての送金、毎年の税金です。実行は決定的です。同じ入力からは、いつも同じ結果が出ます。

## Scene `explain`: まず結果をざっと見る

{sim explain|シム・エクスプレイン}は、最新の実行をざっと確かめるためのコマンドです。最後に各口座に残る金額と、毎年の純資産を表示します。そのあとに警告が続きます。口座の残高がマイナスになりそうなときは、それがいつかを示します。資金不足があっても実行は止まりません。記録されるので、確かめて計画を直せます。そして、この行は、アリスとビルが自分たちで決めたガードレールを支出が越えた年を示しています。

## Scene `networth`: 税引き後の純資産

{sim networth|シム・ネットワース}は、年ごとの純資産を今日のドルで表示します。だから2040年と2026年を公平に比べられます。しかも税引後です。従来型の{IRA|アイ・アール・エー}は、使うときに所得税がかかりますし、証券口座の含み益にも税金がかかります。その繰り延べられた税金を差し引き、さらに4月まで払わない前年分の税金も差し引きます。

## Scene `views`: ひとつの実行を、さまざまな角度から

```slide
heading = "ひとつの実行を、さまざまな角度から"
body = "収入、支出、税金のレポート。シナリオの比較。コードを書かずに使える、グラフ付きのノートブック。"
```

どのレポートも、同じ実行ファイルを読みます。収入、支出、税金のレポートがあり、ふたつのシナリオを並べて比べることもできます。そして、コードを書かずに操作できる、グラフ付きのジュピター・ノートブックもあります。これからの動画で、ひとつずつ見ていきます。

## Scene `ensemble`: たくさんの未来

一回の実行は、ありうる未来のひとつにすぎません。市場もインフレも平均どおりの未来です。でも、本当の未来は平均どおりにはなりません。アンサンブルは同じ計画を何度も実行します。そのたびに、市場の利回りとインフレをランダムに引き直します。{alice crisis|アリス・クライシス}は、{retire alice|リタイア・アリス}を80通りの未来で実行したものです。どの未来にも2008年のような暴落があり、それが2028年から2034年の間、ちょうどふたりの退職の前後に起こります。要約は、年ごとのばらつきを示します。中央値、パーセンタイル、そして最悪の5パーセントの平均です。2040年には、最悪の5パーセントの未来に残る金額は、真ん中の未来の半分を少し超える程度です。これが計画の余裕です。アンサンブルは、良い未来についても悪い未来についても、それを見せてくれます。
