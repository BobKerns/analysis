## Scene `lots`: 口座が持つもの


口座は、実はロットの集まりです。ロットとは、ある時に買った1つの保有のことです。何を持っているかを示します。米国株のような率の系列か、シンボル、つまり株やファンドのティッカーです。いつ買ったかも示し、それで利益が長期か短期かが決まります。そして取得価額、つまり買ったときに払った額を持っています。売るとき、取得価額は税金なしで戻り、税がかかるのは利益だけです。分けていない口座には、{default|デフォルト}という名前のロットが1つだけあります。

## Scene `holdings`: アリスとビルの証券口座

アリスとビルの証券口座には、第3回で作った2つのロットがあります。米国株の率で増える{stocks|ストックス}と、{bonds|ボンズ}です。{sim account lot list|シム・アカウント・ロット・リスト}がそれを並べます。{sim account holdings|シム・アカウント・ホールディングス}は、それぞれの価値も加えます。株は15万ドルで買い、今は24万ドル。そのうち9万ドルは、まだ税がかかっていない利益です。債券の利益は5千ドルだけです。

## Scene `symbol`: ファンドを加える

アリスとビルは、貯金の一部をバランス型ファンドに移したいと考えています。シミュレーターは、ファンドが何を持っているかを知る必要があります。{sim symbol add|シム・シンボル・アッド}は、その名前と比率を記録します。米国株60パーセント、債券40パーセントです。本物のファンドなら価格も取ってきますが、これは作り話なので、{--no-fetch|ダッシュダッシュ・ノー・フェッチ}を付けます。本物のファンドの比率は、AIに聞くか、{sim symbol research|シム・シンボル・リサーチ}で調べられます。やり方はガイドにあります。

## Scene `invest`: 買う

{sim invest|シム・インベスト}で買います。貯金から、証券口座の新しいロット{balanced|バランスト}へ。中身はこのファンドで、来年1月に3万ドルです。1つのコマンドが、1月に買ったロットと、その支払いの送金を書きます。すでに持っている保有なら、代わりに{sim account lot add|シム・アカウント・ロット・アッド}を使います。

## Scene `growth`: ロットの増え方

```slide
heading = "ロットの増え方"
body = [
  "毎月、年率で",
  "自分の系列、なければシンボルの系列、なければファンドの資産クラス",
  "ファンド: 資産クラスを混ぜたもの(株60%、債券40%)",
  "増え方は総リターン: 配当と利子は再投資",
  "アンサンブルでは、どの率も変動できる",

```

各ロットは、毎月、年率で増えます。その率はどこから来るのでしょう? ロットに自分の系列があればそれ。なければシンボルの系列。ファンドなら、持っているものを混ぜたもので、株の率の60パーセントに、債券の率の40パーセントを足します。年とともに中身が変わるターゲット・デート・ファンドは、その年ごとの中身で増えます。リターンの一部は毎年支払われます。株からは配当、債券からは利子で、ロットに再投資されます。そして第6回のアンサンブルでは、どの率も変動させられます。

## Scene `allocation`: 何を持っているか

実行のあと、{sim allocation|シム・アロケーション}は、すべての口座を通して、米国株、債券、現金と、資産クラスごとに合計します。アリスとビルが目指した配分と比べるのは、この数字です。そして{sim account history|シム・アカウント・ヒストリー}に{--lot|ダッシュダッシュ・ロット}を付けると、1つのロットを年ごとに追えます。ここでは、その年ごとのドルで見ます。3万ドルで買ったバランス型ファンドが、毎年増えていきます。配当と利子は取得価額に加わるので、まだ税がかかっていないのは値上がりの分だけです。

## Scene `taxes`: 税金はどこにかかるか

```slide
heading = "税金はどこにかかるか"
body = [
  "現金: 利子に毎年、普通所得として",
  "証券口座: 配当と利子は毎年、残りは売るときに",
  "トラディショナルIRA: 出すお金はすべて普通所得。75歳から最低引き出し",
  "ロス: 5年ルールを満たせば、税金なし",
  "亡くなると、証券口座のロットの取得価額は引き上げられる",
]
```

税金がどこにかかるかは、口座によって違います。現金は利子を生み、毎年普通所得として課税されます。証券口座では、配当と利子は、再投資されても支払われた年に課税されます。配当は、低い譲渡益の税率です。残りの増加分は売るときに課税されます。取得価額は税金なしで戻り、利益はロットを買った時期によって長期か短期になります。トラディショナル{IRA|アイ・アール・エー}から出すお金は、すべて普通所得です。そして75歳からは、最低引き出し額が、それを確実に引き出させます。ロスは、5年ルールを満たせば、税金がかかりません。そして亡くなると、証券口座のロットの取得価額が引き上げられ、その分の利益には税がかかりません。本人名義のロットなら全額、共同名義なら半分、夫婦共有財産の州なら全額です。

## Scene `gains`: 売るとき

ふたりとも引退すると、支出のチェーンはまず債券を売ります。売るたびに、残高に対する割合と同じだけ、ロットの取得価額を持っていきます。債券の利子は支払われたときに課税され、取得価額に加わっていました。だから2031年、ロットは7万4千ドル減り、取得価額は7万2千ドル減ります。ほとんどすべてが、税金なしで戻ってくるのです。{sim report gains|シム・レポート・ゲインズ}は、毎年の利益を示します。実現した利益、つまり売ったか支払われたものと、未実現の利益、つまりまだ口座の中で増えているものです。

## Scene `location`: どのお金をどこに置くか

```slide
heading = "アセット・ロケーション"
body = [
  "同じ投資でも、口座が違えば税も違う",
  "ロス: いちばん伸びるものを。税金はかからない",
  "トラディショナルIRA: どう増えても所得として課税",
  "証券口座: 株。利益は売るまで、または引き上げまで待つ",
  "転換で、お金をIRAからロスへ移す",
]
```

だから、何に投資するかだけでなく、どこに置くかが大事になります。ロスでの増加には税金がかからないので、いちばん伸びるお金を置く場所です。トラディショナル{IRA|アイ・アール・エー}は、どう増えても所得として課税されます。そして証券口座では、株の利益は売るまで、または引き上げまで待ちます。第7回で、アリスは毎年{IRA|アイ・アール・エー}の一部をロスに転換しました。その転換を、もう一度、投資の側から見てみましょう。

## Scene `roth-lots`: 口座ごとに見る転換

{convert|コンバート}では、アリスの{IRA|アイ・アール・エー}は2031年から毎年5万から8万ドルずつ減り、今のドルでおよそ21万3千ドルで止まります。ベースでの額の3分の1にも届きません。だから最低引き出し額も、それにかかる税金も、ずっと小さくなります。ロスには移ってきたものが入っています。取得価額は転換した額で、それを超える分には、決して税金がかかりません。

## Scene `invest-roth`: 1回だけの転換

1回だけの転換も、{sim invest|シム・インベスト}でできます。{IRA|アイ・アール・エー}からロスのロットへ。ここでは、毎年の転換が始まる1年前の2030年1月に、4万ドルを株式インデックス・ファンドへ移します。{--subkind|ダッシュダッシュ・サブカインド}は、新しいロットがロス{IRA|アイ・アール・エー}だと示します。{IRA|アイ・アール・エー}から出たお金はその年の所得として課税され、新しいロットの取得価額は転換した額になります。アリスは59歳半を過ぎています。もっと若い人の場合、転換したお金は、転換ごとに5年たつまで、引き出すとペナルティがかかります。このペナルティは、シミュレーターではまだ扱っていません。

## Scene `location-table`: 口座の種類ごとに

{sim allocation|シム・アロケーション}を税の扱いごとに見ると、それぞれの投資が、課税、課税繰り延べ、非課税のどこにあるかがわかります。2040年には、アリスの{IRA|アイ・アール・エー}の大半がロスに移っています。そして第5回の比較で結果がわかります。追加の転換は、{convert|コンバート}だけの場合より、実行全体で約6千ドル税金が少なく、最後は約4千ドル多く残ります。

## Scene `nb-accounts`: 口座のノートブック

口座のノートブックにも、同じものがあります。保有の表は、口座のロットを、取得価額と利益とともに並べます。その下には、資産クラスごとのポートフォリオが、グラフとともにあります。
