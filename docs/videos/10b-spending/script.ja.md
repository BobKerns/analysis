## Scene `travel`: 任意の支出

もとの計画では、2036年に生活費を月1,000ドル減らします。旅行を減らすのです。2人は、市場が許す限り旅行を続けたいと考えています。新しいシナリオ{travel|トラベル}で、生活費を今から6,500ドルにします。2036年の削減はもう何も変えないので、その説明もそう書き直します。そして旅行を独立したルールにします。月1,000ドル、インフレに合わせて増やし、同じ生活費の口座に払います。何の支出かは、印で示します。{category:living|カテゴリー・リビング}、{health|ヘルス}、{travel|トラベル}は、レポートで支出をまとめる印、{flex:optional|フレックス・オプショナル}は、ストラテジーが変えてよいものの印です。{sim report expenses|シム・レポート・エクスペンシズ}を分類ごとに見ると、2040年は、今日のドルで、生活費が7万8千ドル、旅行が1万2千ドル、医療が1万1千ドルです。

## Scene `as-written`: そのままの計画

1つの未来では、ずっと旅行を続けても問題なさそうです。第6回と同じように、インフレと市場が変わる80の未来を試します。{travel-mc|トラベル・エムシー}です。{sim ensemble summary|シム・アンサンブル・サマリー}は、税引き後の純資産を2045年から示します。真ん中は余裕があります。でも、{CVaR 5|シーバー・ファイブ}、つまり最悪の5パーセントの未来の平均を見てください。2051年からはマイナスになり、2060年には約20万ドルの赤字です。悪い未来では、計画どおりに旅行を続けると、お金が尽きます。

## Scene `kinds`: 4つの決め方

```slide
heading = "毎年1月に決める、4つの方法"
body = [
  "threshold: ポートフォリオが最低額を上回る間だけ旅行する",
  "guardrail: 引き出し率に合わせて10%減らす、または増やす",
  "ceiling_floor: ポートフォリオに合わせるが、変化は年に数%まで",
  "amortize (VPW): 100歳でちょうど使い切る額を使う",
  "cut_on_breach はガードレールに応える(第9回)",
]
```

4つの組み込みのストラテジーが、毎年1月に、任意の支出をいくら使うかを決めます。しきい値は、ポートフォリオが最低額を下回って始まる年には、まるごと使いません。ガイトンとクリンガーのガードレールは、引き出し率が大きく動くと、10パーセント減らすか増やします。上限と下限は、ポートフォリオに合わせますが、1年に動く幅を限ります。そして{amortize|アモタイズ}、つまりVPWは、年下のほうが100歳になるまで、毎年同じだけ払えるとしたらいくらかを使います。5つ目の{cut_on_breach|カット・オン・ブリーチ}はガードレールに応えるもので、第9回で扱いました。

## Scene `threshold`: 最低額を上回るときだけ旅行する

最初は、いちばん簡単なものです。シナリオ{threshold|スレッショルド}に、ストラテジー{spend|スペンド}を加えます。種類はしきい値、{flex:optional|フレックス・オプショナル}の印のルールを受け持ち、前編のポートフォリオを見て、最低額は80万ドル、インフレに合わせて上がります。{sim strategy log|シム・ストラテジー・ログ}は、毎年1月の判断を示します。この1つの未来では、ポートフォリオはずっと最低額を上回るので、毎年旅行します。80の未来では、{sim ensemble spending|シム・アンサンブル・スペンディング}がまとめます。半分の未来で、少なくとも1度は旅行をやめ、平均すると5年に1年は旅行がありません。最悪の年の支出は、10万ドルではなく8万9千ドルです。

## Scene `guardrail`: ガードレール

次は、ガイトンとクリンガーのガードレールを、ふつうの設定で使います。最初の1月が、比べる引き出し率を決めます。約100万ドルのポートフォリオから旅行に1万2千ドル、1.18パーセントです。その後の1月ごとに、ログは何をしたかを示します。率がその前後20パーセントの内側にある間は、そのままです。2029年にはポートフォリオが増え、率が初めより20パーセント以上低いので、旅行を10パーセント増やします。調整した支払いごとの毎月の行は、最後に数だけが出て、{--hook scale|ダッシュダッシュ・フック・スケール}で一覧になります。80の未来では、半分で削減があり、最悪の年の支出は9万2千ドルです。でも、2060年の上のほうを見てください。20に1つの未来が、その年に25万ドルを使います。増額は毎回、前の額の10パーセントで、上限がないので、良い未来では旅行が10倍以上になります。

## Scene `ceiling`: 上限と下限

上限と下限は、上限のある方法です。支出はポートフォリオの一定の割合を目指し、計画から始めますが、インフレを除いて、1年に上がるのは最大5パーセント、下がるのは最大2.5パーセントです。80の未来では、削減は4つの中でいちばん穏やかで、最悪の年も9万4千ドルを使います。2060年の上のほうも、どの年も急には上がれないので、ガードレールより低い22万7千ドルです。

## Scene `vpw`: 使い切る

最後の{amortize|アモタイズ}は、VPW、変動率の引き出しです。毎年1月に、ビルが100歳になるまでに使い切るとしたら、ポートフォリオ全体が毎年、インフレを除いて同じだけ、いくら払えるかを計算します。1年目は計画どおりに使います。その後は、その支払いの変化をすべて旅行が受け取ります。2027年にはポートフォリオが増え、支払いが6,300ドル上がり、そのすべてが旅行に行きます。約1万8,600ドル、計画の1.5倍です。80の未来では、使う額がいちばん多く、真ん中で計画の5分の1増し、20に1つの未来は2060年に60万ドルを使います。削減もいちばん多く、3つに2つの未来です。上限と下限の設定で、上限と下限のストラテジーと同じように、振れ幅を限れます。

## Scene `compare`: 並べて比べる

{sim ensemble compare|シム・アンサンブル・コンペア}は、それぞれのストラテジーの未来を、そのままの計画と対にします。2060年、最悪の5パーセントでは、どのストラテジーも上回ります。いちばん大きいのはしきい値で31万8千ドル、そしてどの分位でも下回らない唯一のものです。やめることしかしないからです。VPWとガードレールは、真ん中と上のほうで大きく下回ります。使ったからです。下の表が底です。そのままでは、最悪の5パーセントは20万ドルの赤字で終わります。しきい値なら10万ドルのプラス、VPWならゼロをわずかに上回り、ガードレールと上限と下限は、まだマイナスです。

## Scene `tradeoff`: それぞれが手放すもの

```slide
heading = "どのストラテジーも、削減と残る額を取り引きする"
body = [
  "threshold: 旅行のない年があるが、底がいちばん高い",
  "guardrail: 小さな削減、上限のない増額",
  "ceiling_floor: いちばん穏やかな削減、より低い底",
  "VPW: いちばん多く使い、いちばん大きく振れる",
]
```

どれかがいちばん良い、ということはありません。しきい値は底をいちばん守りますが、旅行のない年がまるごとあります。ガードレールは少しずつ減らしますが、増やすほうには限りがありません。上限と下限は、減らす量がいちばん少なく、守る量もいちばん少ない。VPWはいちばん多く使い、その支出はいちばん大きく振れます。どの取り引きが合うかは、アリスとビルが決めることです。

## Scene `nb`: アンサンブルのノートブック

アンサンブルのノートブックは、どのレシピでも同じものを描きます。年ごとの支出のばらつきを、点線の計画と並べ、その下に表を出します。ここではガードレールです。真ん中は計画どおりで、増額が積み重なるにつれて、上のほうが広がっていきます。

## Scene `ai`: AIに聞く

```slide
heading = "AIに支出を聞く"
body = [
  "「旅行をやめるのと、短くするのと、どちらがいい?」",
  "「私たちに合う最低額は?」",
  "「VPWの増額に、どう上限を付ける?」",
]
```

ここでもAIアシスタントが役に立ちます。旅行をやめるのか、短くするのか、つまりしきい値と削減の違いを、一緒に考えられます。最低額を選ぶのを手伝い、いくつかをアンサンブルで試せます。そして、VPWに上限を付けるか、上限と下限のストラテジーを使うかで、増額を抑える方法を説明してくれます。
